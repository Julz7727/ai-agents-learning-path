# Notes

One file per finished resource, named after it, for example `anthropic-building-effective-agents.md`.

Every note uses this structure:

1. **What it is** — one or two lines.
2. **What I took from it** — in my own words, no copying.
3. **What I built or tried** — link or description, even if small.
4. **Governance Lens** — what this means for agent identity, permissions, oversight, logging, and control. This section is mandatory. It is the whole reason this repo exists.
