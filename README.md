# AI Agents Learning Path

A curated AI agents learning path, filtered for one specific person: a GRC practitioner with 10 years of IT operations who is building with MCP and learning how agents actually work, in public, in free time.

The source inspiration is Mohini Goyal's "Building AI Agents" roadmap post on X (https://x.com/mohiniuni/status/2113503183997719010). Her list is wide: videos, repos, guides, books, papers, courses. This repo keeps the parts that serve agent building, MCP, and agent governance, and cuts the rest. Full credit to her for the original curation.

## How this works

- Four phases, worked in order, in short sessions.
- Every finished resource gets a note in /notes, written in my own words.
- Every note ends with a Governance Lens: what this means for agent identity, permissions, oversight, and control. That last part is the point. Anyone can learn agents. Fewer people are documenting how to govern them.

## Phase 1: Foundations

Goal: be able to explain how agents work, accurately, in a conversation or an interview.

## Phase 4: The Governance Layer

Goal: my differentiator. For each item from Phases 1 to 3, finish the Governance Lens in its note, then consolidate them into one document: what governing an AI agent actually requires, control by control.

- [ ] All Phase 1 to 3 notes have a Governance Lens section
